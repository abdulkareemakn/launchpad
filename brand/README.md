# Launchpad

The folded L is Launchpad's mark. The diagonal seam separates the upright
from the folded foot; the angled tip suggests lift.

- Master: [`launchpad.svg`](../apps/client/public/launchpad.svg), a transparent,
  single-color SVG. Inline use inherits `currentColor`; image use defaults to black.
- Favicon: [`favicon.svg`](../apps/client/public/favicon.svg), the same mark on
  a white tile for contrast against light and dark browser chrome.
- Documentation uses a copy of the favicon at `docs/docs/assets/favicon.svg`.
  Keep it identical when updating the mark.

Preserve the square viewBox and its built-in clear space. Use the mark beside
the Launchpad name in headers; the mark can stand alone as a favicon or avatar.
The files in `sketches/` are earlier concepts, not the final identity.
