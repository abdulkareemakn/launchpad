This starter kit supports Railway for a hosted application and Docker Compose for a
single-host stack. Both use one Express process to serve the React app and API.
Railway is the recommended student deployment path: GitHub deploys the app, while
MongoDB and a private storage bucket live in the same Railway project.

<CardGroup cols={2}>
  <Card title="Railway" href="/deployment/production" icon="train-front">
    Deploy from GitHub using the Dockerfile. Define the app, MongoDB, and bucket
    with infrastructure as code. Sleeping services have cold starts and usage is
    metered.
  </Card>
  <Card title="Docker and Compose" href="/deployment/docker" icon="container">
    Run the app and MongoDB on a host you manage. Configure HTTPS, production
    storage, backups, and deployment updates yourself.
  </Card>
  <Card
    title="Production build"
    href="/deployment/production-build"
    icon="package"
  >
    Build the client and server for another Node-compatible host with a
    reachable MongoDB database and an S3-compatible storage provider.
  </Card>
</CardGroup>

Before going public, set a unique `BETTER_AUTH_SECRET`, use matching HTTPS origins,
configure the database and storage, verify email delivery, and run the
[security checklist](/reference/security-checklist).
